## 3. 待定项

| ID | 问题 | 建议默认 | 阻塞什么 |
|---|---|---|---|
| T-01 | 数据库 PG vs MySQL | **PostgreSQL + pgvector** | 1.0 开工前定（迁移成本高） |
| T-02 | **App 形态**：Flutter 原生 UI + 内嵌 WebView（仅校务页） vs 整个 App 就是 WebView 壳 | 前者 | **ADR-07 与前端技术栈的全部结论** |
| T-03 | 校方 OAuth/CAS 何时谈成 | 1.0 不依赖，1.1+ 增强 | 不影响 1.0 |
| T-04 | Web 端形态 | Flutter Web 复用，只放开基础功能 | 1.0 第 3 周 |
| T-05 | iOS / 鸿蒙 | 1.3 实验分支 | 不阻塞 |

> **T-02 是最急的一个**：它决定"UI 用 Flutter 写还是用网页写"，差一整套前端工程量。

## 4. 版本路线（摘要）

| 版本 | 主题 | 关键交付 |
|---|---|---|
| **1.0** | MVP + 生产级重构 | 旧 Demo 全部行为 + 多用户鉴权 + 流式 + 双通道模型 + 课表/日程 + 基础可观测 + CI |
| **1.1** | 能力补齐 | RAG（公共向量 + rerank）、Memory 质量、日志面板、自习室查询、支付、**E2EE 备份（可选）** |
| **1.2** | 日历导出 | ICS 导出、提醒、周次展开 |
| **1.3** | 兼容性实验 | 鸿蒙 / iOS 实验分支，不承诺 |
