# 云农之窗 · 接口文档（API v1.0）

| 项 | 内容 |
|---|---|
| 文档版本 | **v1.0**；旧 Demo 的 15 个接口见 [v0-审计/03-接口文档.md](v0-审计/03-接口文档.md) |
| 契约来源 | `shared/` Rust 类型 + 生成的 JSON Schema（本文档为人工说明，**以 Schema 为准**） |
| 范围 | ① 云端 HTTP（套餐/知识/用量）② 端侧本地接口（Rust Core）③ WebView 桥 ④ 三协议适配内部契约 |

> **两条边界先记住**
> 1. **BYOK 的模型请求不经过我们**：客户端直连厂商，本文只描述"我们自己的接口"。
> 2. **会话正文不上云**：云端接口收到的 `messages` 只在内存中转发，不落库（见 [设计文档 ADR-04](02-系统设计文档.md)）。

## 1. 通用约定

| 项 | 规定 |
|---|---|
| Base URL | `https://api.<domain>/api/v1`（本地 `http://127.0.0.1:8080/api/v1`） |
| 版本 | 路径版本 `/api/v1`；破坏性变更才升 v2 |
| 编码 | UTF-8；`application/json; charset=utf-8` |
| 时间 | RFC3339 UTC（`2026-10-31T09:52:40Z`），客户端负责转本地时区 |
| 鉴权 | `Authorization: Bearer <access_token>`；`/healthz` `/readyz` `/auth/*` 除外 |
| 追踪 | 响应头 `X-Request-Id`；请求可带 `X-Request-Id` 由服务端回显 |
| 幂等 | 金额/发码类接口需 `Idempotency-Key`（1.1 支付起） |
| 限流头 | `X-RateLimit-Remaining`、`Retry-After`、`X-Quota-Tokens-Remaining` |
| 分页 | `?limit=` (≤100) + `?cursor=`；响应 `next_cursor`（不透明字符串） |

### 1.1 成功响应

```json
{ "ok": true, "data": { }, "request_id": "req_9f3c" }
```

### 1.2 失败响应

```json
{
  "ok": false,
  "error": {
    "code": "QUOTA_EXCEEDED",
    "message": "本月配额已用完，可升级套餐或改用自带 Key",
    "request_id": "req_9f3c",
    "details": { "remaining": 0, "reset_at": "2026-11-01T00:00:00Z" }
  }
}
```

### 1.3 错误码总表

| code | HTTP | 含义 | 客户端动作 |
|---|---|---|---|
| `UNAUTHORIZED` | 401 | 无/过期 token | 刷新 token，失败则登录 |
| `TOKEN_EXPIRED` | 401 | access 过期（可区分） | 用 refresh 换新 |
| `FORBIDDEN` | 403 | 越权 | 提示无权限 |
| `NOT_FOUND` | 404 | 资源不存在 | 回到列表 |
| `VALIDATION_ERROR` | 422 | 参数非法 | 提示字段 |
| `MESSAGE_TOO_LARGE` | 413 | 超单轮上限 | 提示压缩/分次 |
| `CONCURRENCY_LIMIT` | 429 | 已有在途请求 | 等待/取消旧的 |
| `RATE_LIMITED` | 429 | 频率超限 | 按 `Retry-After` 重试 |
| `QUOTA_EXCEEDED` | 402 | 配额耗尽 | 引导升级/换 BYOK |
| `REVIEW_REJECTED` | 403 | Auto Review 拒绝 | 展示 reason，不建议重试 |
| `UPSTREAM_TIMEOUT` | 504 | 上游超时 | 可重试一次 |
| `UPSTREAM_ERROR` | 502 | 上游错误 | 可重试；连续失败引导换模型 |
| `INTERNAL` | 500 | 未捕获 | 展示 request_id |

## 3. 模型与对话

### 3.1 `GET /providers`

返回可用的模型与协议组合（**不含任何 Key**；BYOK 用户据此渲染下拉框）。

```json
{
  "ok": true,
  "data": {
    "protocols": ["openai_completions", "openai_responses", "anthropic_messages"],
    "models": [
      { "id": "deepseek-chat", "protocol": "openai_completions", "context": 128000, "channels": ["byok", "plan"] },
      { "id": "claude-x", "protocol": "anthropic_messages", "context": 200000, "channels": ["byok"] }
    ]
  }
}
```

> BYOK 用户还可以在设置里填**自定义 Base URL + 模型名**，服务端不做白名单限制（我们不经手其流量）。

### 3.2 `POST /chat/stream`（套餐通道，主接口）

**请求**

```json
{
  "session_id": "s_123",
  "turn_id": "t_88",
  "round": 1,
  "model": "deepseek-chat",
  "protocol": "openai_completions",
  "messages": [
    { "role": "system", "content": "..." },
    { "role": "user", "content": "下周三下午有课吗" }
  ],
  "tools": [ { "name": "get_courses", "parameters": { } } ],
  "max_output_tokens": 1024,
  "stream": true,
  "estimated_input_tokens": 3120
}
```

| 字段 | 说明 |
|---|---|
| `session_id` | 端侧生成，服务端只用于配额归集，**不落库** |
| `turn_id` | **一次用户提问**的唯一 id；多轮工具循环共享它，**并发闸门按 turn 计，不按 HTTP 请求计**（否则第 2 轮被自己第 1 轮的闸门挡住） |
| `round` | 第几轮（1..4）；同一 `turn_id` 内唯一，重复提交按幂等丢弃 |
| `messages` | 端侧装配好的完整上下文，**必须 append-only**（见 §3.4） |
| `tools` | 工具声明（端侧提供，服务端原样转发，**从不执行**） |
| `estimated_input_tokens` | 端侧估算，用于**先拒后转**（超额直接 413，不产生上游费用） |

**响应**：`200 text/event-stream`

```
event: meta
data: {"request_id":"req_9f3c","model":"deepseek-chat","channel":"plan"}

event: delta
data: {"text":"下周三下午"}

event: tool_call
data: {"id":"c1","name":"get_courses","arguments":{"weekday":3,"week":9}}

event: usage
data: {"tokens_in":3120,"tokens_out":96,"estimated":false}

event: done
data: {"finish":"stop","cost_cents":1}
```

**规则**

- 客户端断开连接 → 服务端**立即取消上游请求**（不继续计费）；
- 单用户同时只允许 1 个在途流，第二个返回 `429 CONCURRENCY_LIMIT`；
- 心跳：每 15s 一条 `event: ping`；
- 审核失败：先 `event: error`（`REVIEW_REJECTED`）再关闭连接。

### 3.3 `GET /chat/{request_id}`（可选，1.1）
用于断线后查询该次调用是否已完成（**不返回内容**）。

### 3.4 工具循环（多轮，见 [ADR-05](04-ADR.md)）

模型返回 `tool_call` 时，**客户端执行工具**，然后以同一 `turn_id`、`round+1` 再发一次请求；`messages` 末尾追加 `assistant(tool_call)` 与 `tool(tool_result)`。

```
round 1: user ──▶ [stream] ──▶ tool_call(get_courses)
round 2: + tool_result ──▶ [stream] ──▶ delta … done
```

| 约束 | 说明 |
|---|---|
| **最多 4 轮** | 超过即强制收尾（`done.finish="max_rounds"`） |
| **append-only** | 只在末尾追加；**禁止重排、禁止中途压缩**——否则厂商 prompt cache 失效，成本翻倍。压缩只在一轮结束时做 |
| **按轮幂等** | `(turn_id, round)` 唯一；重复提交返回同一 `request_id`，不重复转发、不重复计费 |
| **并发按 turn 计** | 整个 turn 只占 1 个并发名额；轮次之间释放上游连接，**但不释放名额** |
| **工具不执行** | 服务端只转发 `tools` 与 `tool_result`，不解析、不执行、不缓存 |

取消：`DELETE /chat/turns/{turn_id}` → 中止剩余轮次并释放名额。

## 4. 知识库（RAG）

### 4.1 `POST /knowledge/search`

两条通道都用这个接口（ADR-05）。

```json
{ "query": "云南农业大学 转专业 条件", "top_k": 5, "filters": { "doc_type": "regulation" } }
```

```json
{
  "ok": true,
  "data": {
    "chunks": [
      { "id": "c_88", "doc_id": "d_7", "title": "本科生转专业管理办法",
        "content": "……", "score": 0.83, "citation": "[K:d_7#c_88]" }
    ],
    "took_ms": 42
  }
}
```

> 返回的 `content` 由端侧拼进上下文；**服务端不记录 query 与用户 id 的关联**（只记命中率匿名指标）。

### 4.2 `GET /knowledge/docs?cursor=&limit=`
分页列出知识文档（公开可查，`status=approved` 才会有内容）。

### 4.3 `POST /knowledge/docs`（管理员/审核后入库）

```json
{ "title": "本科生转专业管理办法", "source_url": "https://...", "license": "public", "content": "全文……" }
```
→ `201 { "doc_id": "d_7", "status": "pending" }`（需审核通过才可检索）

### 4.4 `DELETE /knowledge/docs/{doc_id}`
软删除：chunks 从检索中移除，保留审计记录。

## 5. 授权时效与成本监控

> **计费模型：按时间授权，不按 token 记账**（[ADR-03](04-ADR.md)）。
> token 只做 **1% 抽样**，用途是**成本监控与熔断**，不用于计费；因此这张表里没有"余额"，只有"有效期"。

### 5.1 `GET /quota`

```json
{ "ok": true, "data": {
  "channel": "plan",
  "plan": "plan_30d",
  "entitlement_expires_at": "2026-11-30T00:00:00Z",
  "concurrent_limit": 1,
  "max_input_tokens": 32000,
  "knowledge_rpm": 30,
  "sampled_cost_cents_7d": 12 } }
```

- `channel`：`plan`（代理）/ `byok`（直连，此接口只返回 `knowledge_rpm` 等公共项）；
- `sampled_cost_cents_7d`：近 7 天抽样成本估计，仅用于"给你自己看的账单感"。

### 5.2 `GET /usage?period=day|month`

```json
{ "ok": true, "data": {
  "period": "month", "sampled": true, "sample_rate": 0.01,
  "est_tokens_in": 812000, "est_tokens_out": 96000,
  "est_cost_cents": 240,
  "records": [ { "req_id": "req_9f3c", "model": "deepseek-chat",
                 "tokens_in": 3120, "tokens_out": 96, "round": 1,
                 "created_at": "2026-10-31T09:52:40Z" } ],
  "next_cursor": null } }
```

> **`sampled: true` 是刻意的**：这不是账单，是监控样本。别把抽样数字当计费依据写进 UI。

### 5.3 `GET /plans`

```json
{ "ok": true, "data": [ { "code": "plan_30d", "name": "30 天不限量", "valid_days": 30, "price_cents": 990 } ] }
```

### 5.4 `POST /redeem`

```json
{ "code": "YNAU-ABCD-1234" }
```
→ `200 data: { "plan": "plan_30d", "valid_days": 30, "entitlement_expires_at": "2026-11-30T00:00:00Z" }`
错误：`NOT_FOUND`（无效码）、`FORBIDDEN`（已被使用）。

### 5.5 成本熔断（服务端内部，无对外接口）

```
每小时扫描抽样成本：
  cost_user > 20 × 均值   → 临时限流 + 告警（不封号，先看）
  cost_global > 阈值      → 收紧全局闸门（50 → 30），并通知管理员
```


## 8. WebView JS Bridge（校务取数）

> 只在 App 内部，不过网络。目的：把"用户自己的会话"变成结构化数据。

### 8.1 消息格式

```json
{ "v": 1, "type": "timetable", "page_url": "https://...", "captured_at": 1761923560,
  "html": "<table id=\"timetable\">…</table>" }
```

| type | 载荷 | 说明 |
|---|---|---|
| `login_done` | 无 | 检测到已登录（URL/元素特征） |
| `timetable` | `html` | 课表页 HTML，端侧解析 |
| `score` | `json` | 成绩接口 JSON（若页面本身是 XHR 渲染，则注入 hook 取） |
| `exam` | `html` | 考试安排 |
| `error` | `{code, message}` | 抓取失败（未登录/网络/页面改版） |

### 8.2 端侧解析产物

```json
{ "term": "2026-2027-1",
  "courses": [ { "name": "高等数学A", "weekday": 1, "start_period": 1, "end_period": 2,
                 "weeks": "1-16", "room": "东校区1教305", "teacher": "张老师" } ] }
```

**失败姿势**：页面改版时解析必须**显式失败**并提示"学校页面可能已更新，请反馈"，不允许静默产出空课表（v0 的教训）。

## 9. 三协议归一化契约（内部）

```rust
struct ChatRequest { messages: Vec<Msg>, tools: Vec<ToolSpec>, max_output_tokens: u32, temperature: f32 }
enum Chunk { Text(String), ToolCall{ id, name, args }, Usage{ in_tokens, out_tokens }, Done{ finish } }
```

| 归一化字段 | Completions | Responses | Messages |
|---|---|---|---|
| 系统提示 | `messages[0]` | `instructions` | `system` |
| 工具 | `tools[].function` | `tools[]` | `tools[].input_schema` |
| 文本增量 | `choices[0].delta.content` | `output_text.delta` | `content_block_delta.text` |
| 工具增量 | `delta.tool_calls[]` | `function_call_arguments.delta` | `input_json_delta` |
| 结束原因 | `finish_reason` | `status` | `stop_reason` |

> 适配器**必须**产出一致的 `Chunk` 序列；契约测试对三协议跑同一组 fixture。

## 10. SSE 规范（套餐通道）

| 项 | 规定 |
|---|---|
| Content-Type | `text/event-stream; charset=utf-8` |
| 缓存 | `Cache-Control: no-cache`，禁用代理缓冲（`X-Accel-Buffering: no`） |
| 事件 | `meta` `delta` `tool_call` `tool_result` `usage` `done` `error` `ping` |
| 心跳 | 每 15s `event: ping` |
| 顺序 | `meta` 必首，`done`/`error` 必末且唯一 |
| 取消 | 客户端关闭连接；或 `DELETE /chat/{request_id}` |
| 重连 | 不重放历史（内容已在端侧）；重连即新请求，需客户端去重 |

## 11. v0 → v1 迁移映射

| v0（旧 Demo 实测） | v1.0 | 变化 |
|---|---|---|
| `POST /api/chat` | `POST /api/v1/chat/stream`（套餐）/ 端侧直连（BYOK） | 非流式 → SSE；无鉴权 → Bearer |
| `POST /api/vision` | `files_parse`（端侧）+ gateway 视觉调用 | 端侧解析，不落地服务器 |
| `POST /api/upload_file` | `files_parse`（本地）/ `POST /api/v1/knowledge/docs`（入库） | 二选一，语义拆开 |
| `GET /api/file_state` | 端侧 SQLite 查询 | 不再有服务端状态 |
| `POST /api/upload_file/clear` | `files_delete` | 本地 |
| `GET /api/profile` | `memory_*`（本地） | 画像变成记忆条目，可编辑 |
| `POST /api/profile/delete` | `memory_delete` | 本地 |
| `POST /api/profile/reset` | `memory_clear(kind=auto)` | 本地 |
| `POST /api/clear` | `memory_delete(session)` | 本地 |
| `GET /go/{action}` | 客户端导航 + WebView | 不再服务端 307（Web 版保留） |
| `GET /api/schedule` | `courses_query`（本地） | 支持按周查询 |
| `GET /api/test` | `GET /healthz` | 语义变更 |

## 13. 兼容与弃用

1. 新增字段**不算**破坏性变更；删除/改语义才算；
