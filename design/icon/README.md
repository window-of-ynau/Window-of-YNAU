# 云农之窗 · 应用图标（t157）

三稿全部在 `design/icon/` 下，**只出稿、未接线**（`app/**` 未改）。

## 一、三稿概览

| 稿 | 图形 | 一句话 | 适用 |
|---|---|---|---|
| **V1 窗格**（推荐） | 圆角纸色瓦片 + 墨黑"2×2 窗格" + 右下角一格赤陶色 | 名字里的"窗"就是它：十字窗棂 + 一格亮色 | 通用；16px 下仍能读出"窗格" |
| **V2 田垄** | 三条横带（中间一条赤陶） | 农业 + 田垄，最"农" | 更像列表/菜单，16px 下辨识度低于 V1 |
| **V3 墨瓦** | 墨黑瓦片 + 纸色窗格（负形） | 反色版本，深色任务栏最稳 | 深色优先；浅色任务栏会成一块重色方块 |

**推荐 V1**：它在浅/深两种任务栏上都能成立（瓦片亮，浅底靠墨色图形、深底靠亮瓦片），且 16px 下仍保留"外框 + 十字 + 一格填色"三要素。

## 三、图形含义

- **窗格**：产品名"云农之窗"里的"窗"。十字窗棂同时也是"田"字的骨架——**一个图形同时装下"窗"和"农"**。
- **一格赤陶色**：来自 C 主题的强调色 `#A9583E`，表示"已经打开/当前这一格"，也让图标在 16px 时有一个**颜色锚点**（纯黑会糊成一块）。
- **瓦片与描边**：瓦片是 C 主题的纸色 `#FAF9F5`；描边 `rgba(20,20,19,.10)` 只在 ≥64px 时可见，用来在浅色背景上给瓦片一个边界。

## 四、为什么小尺寸仍然清晰

| 尺寸 | 关键笔画 | 结果 |
|---|---|---|
| 1024 | 窗棂 104px、瓦片圆角 208px | — |
| 32 | 窗棂 3.25px、填色格 9px | 能看出窗格 + 一格色块 |
| **24** | 窗棂 2.4px、填色格 6.8px | 能看出"田"字结构 |
| **16** | 窗棂 **1.6px**、填色格 4.5px | 仍可辨认：外框 + 十字 + 右下角暖色 |

三条硬规则：
1. **笔画全部 ≥ 100/1024**（16px 时 ≈1.6px），不用 1px 描边、不用细线；
2. **只有 4 个视觉元素**（外框、横棂、竖棂、一格填色），没有第二层细节；
3. **没有文字**、没有渐变、没有阴影——这三样在 16px 一定会糊。

## 五、与三套主题的关系

| 主题 | 关系 |
|---|---|
| A 极简黑白 | 图标主体是墨黑（`#141413`），与 A 的黑白语汇一致；瓦片纸色让它在浅色桌面不"融掉" |
| B 深蓝玻璃 | 图标不用蓝（避免与系统图标抢色）；瓦片在深色任务栏上是亮矩形，天然可辨 |
| C 书本质感 | 瓦片=纸色、强调色=赤陶，直接沿用 C 的 token 值 |

## 六、接线（下一轮，另派）

- Windows：`app/windows/runner/resources/app_icon.ico` 替换 + `Runner.rc` 里 `IDI_APP_ICON` 指向即可；
- Android：`android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` 指向 `ic_launcher_foreground`（432 前景）与 `ic_launcher_background`（432 背景），传统 mipmap 用 `icon-48/72/96/144/192` 缩放；
- 桌面窗口图标（Flutter 运行时）：`window_manager` 的 `setIcon` 用 `icon-256.png`。

## 七、已知取舍

- V2 在 16px 下会退化成"三条横线"，更像菜单图标——所以不作为推荐稿；
- V3 的墨瓦在浅色任务栏上是一块重色方块，视觉重量偏大；
- 真机（Windows 任务栏 24px、开始菜单 48px）的观感建议 owner 装上后确认一次：本稿的预览是真实 PNG 渲染，但 DPI 缩放（125%/150%）下的插值仍以系统为准。
